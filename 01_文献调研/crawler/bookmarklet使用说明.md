# 书签脚本使用说明

## 操作步骤

### 第一步：添加书签
1. 在浏览器中新建一个书签（收藏夹）
2. 书签名称随意填写，如：`提取论文标题`
3. 书签地址（URL）填入 `bookmarklet.js` 文件中的全部代码

### 第二步：登录并搜索
1. 打开 http://jour.ucdrs.superlib.net/
2. 登录你的账号
3. 在搜索框输入关键词，例如：
   - `危险化学品安全`
   - `危化品运输`
   - `化工安全监管`
   - `危险化学品储存`
   - `消防安全`
4. 点击搜索，等待结果加载完成

### 第三步：运行书签脚本
1. 在搜索结果页，点击你刚才添加的书签
2. 脚本会自动提取当前页所有论文信息
3. 浏览器会弹出下载，保存为 JSON 文件（文件名含关键词和日期）
4. 将下载的 JSON 文件放入 `../data/` 目录

### 第四步：翻页继续提取
- 点击下一页，再次点击书签，继续提取
- 建议每个关键词提取 3~5 页（约 30~50 篇）

### 第五步：运行分析脚本
```bash
python ../crawler/analyze.py
```
分析结果会输出到 `../data/分析报告.txt`
