# 化工安全毕业论文写作计划

## 项目概述

本项目为化学安全方向专科毕业论文的完整写作流程，涵盖选题调研、大纲确定、内容撰写到查重检测的全过程。

- **论文方向**：危险化学品运输安全监管（已确定结构框架）
- **查重要求**：维普平台检测，格式规范检测 < 2%，内容查重 < 20%
- **参考文献**：不少于 15 篇，格式参照期刊引用规范

---

## 整体工作流程

### 第一阶段：文献调研与选题分析（当前阶段）

**目标**：通过爬取/收集近年来知网、万方等平台上与"危险化学品安全"相关的公开论文信息，分析高频选题方向、研究角度和参考文献资源。

**具体步骤**：
1. 编写 Python 爬虫脚本，抓取知网/万方等平台论文元数据（题目、作者、摘要、关键词、发表年份）
   - 关键词：`危险化学品安全`、`危化品运输`、`化工安全监管`、`消防安全`、`职业卫生`
   - 年份范围：2019–2024 年
2. 对爬取结果进行统计分析：
   - 高频关键词词云
   - 各子方向论文数量趋势
   - 常被引用的核心参考文献
3. 输出《选题方向分析报告》，辅助最终选题决策

**注意事项**：
- 知网对爬虫有反爬限制，可结合手动导出 + 脚本解析的方式
- 优先使用公开可访问的学术搜索接口（如语义学者、百度学术等）作为补充

### 第二阶段：确定选题与输出大纲

**输入**：用户选定的论文题目和核心研究角度  
**输出**：完整的章节大纲（含各小节的写作要点提示）

### 第三阶段：分章节内容撰写与润色

**目标**：逐章扩展正文内容，确保论述逻辑清晰、语言规范、学术性强。

**工作方式**：
- 每次处理 1–2 个小节，逐步完成全文
- AI 起草初稿 → 用户审阅修改意见 → AI 润色定稿
- 严格控制语言风格：避免口语化，使用学术表达
- 适时插入数据、案例、法规依据（来源于参考文献）

**字数目标**（专科毕业论文参考）：
- 正文总字数：8,000–12,000 字
- 摘要：300–500 字（中英文各一份）

---

### 第四阶段：查重与定稿

**目标**：提交维普查重，确保通过学校要求的查重标准。

**步骤**：
1. 将完整论文导出为 Word 格式（.docx）
2. 提交维普"创作力"平台检测：
   - 格式规范检测 < 2%
   - 内容相似度 < 20%
3. 根据查重报告，针对性修改高相似段落（同义替换、结构调整、改写引用方式）
4. 再次检测直至通过，输出最终定稿

**降重技巧（备用）**：
- 避免整段复制，改为概括性转述
- 引用数据时加入自己的分析评论
- 参考文献的表述换成间接引用形式
